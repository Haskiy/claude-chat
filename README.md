# Claude Chat

一个运行在浏览器中的 Claude AI 聊天 PWA 应用。

## 使用方式

1. 浏览器打开 https://haskiy.github.io/claude-chat/
2. 点右上角齿轮 → 输入你的 Anthropic API Key → 保存
3. 开始聊天

## 功能特点

- 流式实时回复（打字机效果）
- Markdown 渲染（代码块、标题、列表等）
- 支持 Sonnet 4 / Haiku 3.5 / Opus 4 模型切换
- 深色模式自动适配
- 数据仅存储在浏览器本地
- 可添加到 iPhone 主屏幕使用

## 隐私

- 代码完全开源透明
- API Key 存储在浏览器本地，不会上传任何服务器
- 不追踪、不收集任何数据
